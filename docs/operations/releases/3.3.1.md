# SpringSuite 3.3.1

## Browser Notifications

- Added a bounded `BrowserNotificationRotator` queue for SQL Request Journal events.
- The first event is displayed immediately; subsequent events rotate no faster than once per second.
- Only one native Browser Notification remains visible at a time, preventing Windows notification stacking during request bursts.
- Added configurable notification lifetime: 3, 5, 8, 15 or 30 seconds; default is 8 seconds.
- The selected lifetime is persisted in browser `localStorage` and applied to the currently visible notification.
- Duplicate active or queued request IDs are suppressed.
- Disabling notifications or closing the dashboard clears the queue, timers and active Browser Notification.

## Verification

- Added deterministic Node tests with a virtual clock for lifetime, rotation, deduplication, click handling and cleanup.
- `verifyDeployLayout` now runs the Browser Notification test suite and requires `static/js/browser-notifications.js` in the deployment image.
