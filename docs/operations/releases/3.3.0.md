# SpringSuite 3.3.0

## Focus

Control-plane stabilization and operator experience.

## Changes

- Unified version source for controller, bootstrap, preloader, tray, and toast broker.
- Simplified tray menu with one context-sensitive lifecycle action.
- Transparent owner-drawn tray menu icons that remain visible during hover and selection.
- Monotonic, state-driven PreStart progress with stale-controller protection.
- Interactive bootstrap now repairs and starts the user-session tray broker.
- Controller state text is sanitized before publication; corrupted Unicode is replaced by a safe lifecycle message.
- Runtime Doctor now reports an explicit overall result, release version, failures, warnings, and detailed checks.

## Compatibility

- Runtime state schema remains `springsuite.runtime-controller-state.v1`.
- Existing controller configuration remains valid.
- Update and rollback manifests retain their current format.
